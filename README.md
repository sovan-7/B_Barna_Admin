# B_Barna Web Admin

<p>A Flutter Web admin dashboard for managing the <strong>B_Barna</strong> e-learning platform, backed by Firebase (Auth, Firestore, Storage).</p>

## Features

<ul>
<li><strong>Courses</strong> — courses, subjects, units, and topics management</li>
<li><strong>Quiz &amp; Questions</strong> — build quizzes and question banks</li>
<li><strong>Live Classes</strong> — schedule and manage live sessions</li>
<li><strong>Teachers &amp; Students</strong> — manage profiles, access, and roles</li>
<li><strong>Documents</strong> — upload and organize PDFs, audio, and video</li>
<li><strong>Banners</strong> — manage promotional banners shown in the app</li>
</ul>

## Tech Stack

<ul>
<li><a href="https://flutter.dev/">Flutter</a> (Web)</li>
<li><a href="https://pub.dev/packages/provider">Provider</a> for state management</li>
<li><a href="https://firebase.google.com/">Firebase</a> — Authentication, Cloud Firestore, Storage</li>
</ul>
